# Benefit-Harm

A Shinylive app (runs in the browser, no server needed) for exploring adolescents' views of helping and aggressing behaviors.

Based on: McCarty, S.M., & Dunsmore, J.C. (2023). Adolescents' perceptions of helping and aggressing at school: Salience of benefit-harm, extent of impact, and collective dyadic power. *Current Psychology*. https://doi.org/10.1007/s12144-022-03806-4

**Live app:** https://shanemccarty.github.io/benefit-harm/

## Versions
- **v1:** Created Spring 2021 by Shane McCarty and Bryan Acton.
- **v2:** Updated with Claude Sonnet 5.5 in Fall 2026.

## Files
- `app/` - the Shiny app and its data
- `docs/` - the exported Shinylive site shown by GitHub Pages
- `export.R` - rebuilds `docs/` after changing the app
